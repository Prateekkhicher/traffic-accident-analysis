# 🚗 Traffic Accident Analysis (Python + SQL)

## 📌 Project Overview
This project analyzes traffic accident data using Python (Pandas, Seaborn, Matplotlib) and SQL to identify patterns in accident frequency, severity, and contributing factors.

---

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy)
- Seaborn & Matplotlib
- MySQL
- SQLAlchemy

---

## 📊 Key Insights
- Accidents are highest at night and during bad weather conditions.
- Higher speeds and alcohol involvement lead to more severe accidents.
- High-risk combinations like Night + Rain increase accident probability.

---

## 📁 Project Structure
- `traffic_analysis.ipynb` → Full analysis
- `clean_accident_data.csv` → Dataset
- SQL queries included in notebook
